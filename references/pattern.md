# 52×52 自由色施工图

## 原画与颜色

复杂版从用户指定的原始手绘插画重新采样。默认 nearest 等比 contain 为 52×52；不抖动、不吸附品牌色、不设固定颜色上限。默认基于 Lab 色差平稳主要色面，合并相近色和低对比小色簇，并保护高对比五官与透明轮廓；`--raw-colors` 关闭处理以保留采样 RGB。脚本，不自动把近黑/近白改成纯黑/纯白；五官需要加强时先在插画层编辑，用户同意后再制图。

不要承诺 52×52 完全保留高分辨率笔触。如果眼睛的三个区域在采样后消失，报告实际问题；需要扩大眼睛或局部调整豆位时保持大小眼与神态，不把纯排版修改变成造型修改。

默认减少无意义杂色，保留关键色块层次，提供完整 CSV；不能为缩短图例额外强制限色。自由色是忠实的视觉设计数据，不是数千种豆子的已验证采购清单。需要真实品牌材料时，另行明确颜色库、来源、匹配方法与损失，再做品牌版。

## 命令

```sh
node scripts/generate.cjs input.png --out output/猫咪_v1 --title "猫咪 · 手绘复杂版"
node scripts/generate.cjs input.png --out output/猫咪_v2 --background alpha --full-legend
```

选项：

- `--out PREFIX`：必填，输出到此前缀；已有目标文件时拒绝覆盖，请换版本号。
- `--title TEXT`：默认“宠物头像 · 手绘复杂版”。
- `--size N`：默认 52；仅用户明确要其他尺寸时改变（4–150）。
- `--background auto|white|alpha|none`：默认 auto。auto 在原图存在非完全不透明像素时按 alpha；否则按边界连通近白留空。white 模式同样处理透明区，并只删除与画布边界连通的近白区域；alpha 不删除不透明白色；none 保留原图白色，contain 留白仍为空位。背景接近白色的实物可能误删，必要时请用户提供透明底稿或改用 alpha。
- `--white-threshold N`：白底背景阈值，默认 240（0–255）。
- `--raw-colors`：关闭默认减少杂色处理，逐豆保留原色。默认色数随内容与色差变化，不固定为 36 色。
- `--full-legend`：另导出分分页的完整颜色图例（每页最多 160 色），避免超长单张图。

## 输出契约

- `_52x52导入.png`：默认 52×52、白底 RGB PNG，方便以图片导入拼好豆。App 的实际导入映射由 App 决定，本工具不生成或宣称兼容其私有项目文件。
- `_像素预览.png`：nearest 放大，每格保持清楚，不使用平滑缩放。
- `_施工图.png`：深色标题栏、格内短数字编号、四周坐标、每 5 格加重线、实际颜色数与总豆数，说明编号非品牌色号。
- `_像素数据.json`：`null` 为空格，`#FFFFFF` 是有豆的白色。行优先数组，长度 N²；包含自由色编号、HEX/RGB/count、采样方式与背景方式。
- `_编号颜色用量表.csv`：UTF-8 BOM，格内编号/HEX/R/G/B/数量，完整覆盖所有前景颜色。
- `_颜色图例_页NNN.png`：仅 `--full-legend` 导出，所有页合计覆盖全部颜色。

白底导入 PNG 本身无法区分留空与白珠，JSON 和带编号施工图保留该区别。若用户需要透明导入，可从 JSON 另行生成，不声称白底 PNG 已携带空位语义。

## 校验与交付

运行脚本输出统计和 `npm test`。确认尺寸 N×N、像素数组 N²、occupied cells = CSV 数量合计、JSON 色数 = 唯一前景色数、图纸编号与 CSV 一致、白色豆位不被视为空格。按需要做像素级五官检查；图纸最终观感由用户查看，不声称已经在 App 中测试。

报告图纸、导入图、预览、CSV、总豆数和实际色数。保留原画和历史版本；五官编辑应另存新底稿。材料种类很大时清楚披露，不把 RGB 索引写成 MARD/COCO 等真实色号。
