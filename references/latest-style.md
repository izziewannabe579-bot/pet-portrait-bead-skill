# 简笔粗笔触宠物头像：项目最新风格拆解

本文件同步自项目最新确认的绘画规则。适用于用户指定的“米色帽子粗笔触”参考或同类简笔手绘风格，不把此画法覆盖到用户后来指定的其他风格。

参考文件相对位置：`风格参考/简笔宠物头像-米色帽子粗笔触.png`。需要实际查看并作为图像生成输入；本仓库不附图片。以下描述的是可见观感，不推定作者实际材料。

## 决策要点

- **形状先于纹理**：用几块大形建立头、耳、口鼻及配饰，再以少量笔触提示毛簇。紧凑、略不规则、自然不对称；不逐点复刻照片或追求精确写实体积。
- **笔触构成造型**：宽而钝的短笔触呈扇形或放射状组成额头、眉毛、脸颊和口鼻；长弧形笔触表现垂耳或配饰。宽度、长度、方向有变化，带轻微断裂、露底和干刷颗粒，不均匀撒噪点、不逐根画细毛。
- **少量叠色、弱体积**：大面积不透明水粉色块为主，局部一层浅色或深色粗笔触提示结构。采用离散色块，不用连续渐变、柔焦、复杂环境光或多层细碎高光；“水粉质感”不等于精雕厚涂。
- **主色块关系，而非强制限色**：该参考的炭黑、灰、奶白、暖米黄建立主次，五官最深、口鼻最亮、帽子柔和。其他动物保留其照片毛色与眼色，不硬套黑白配色。减少视觉重复叠色不意味着限制 RGB 数量；施工图仍为不限色复杂版。
- **表情靠位置和几笔线条**：眼部明亮区域与深色瞳孔形成对比，可略夸张圆度；深色鼻块、短而略歪的嘴线表现认真、无辜或困惑。按目标动物可见结构表达虹膜、眼白与高光，不强加人类眼白，不移植参考狗的耳形与口鼻。
- **线与块混用**：色块和毛簇边缘形成主体外轮廓，不用闭合深线包住动物。鼻嘴、帽带、绳圈可用少量粗而略抖的线，具有轻重、断续与手工误差，不变成光滑矢量曲线。
- **配饰只画识别信息**：轮廓、帽带和少量弧线表示帽子结构；织物只保留几笔暗示，不逐针画针织或真实绳索反光。配饰不能比五官更精细或抢眼，且仅保留用户要求的配饰。
- **构图与背景分开**：居中小头像、大留白、无身体或场景叙事，按用途调整占比并保留完整耳朵和配饰。参考中的暖色纸底与纸纹不是必要画法；默认真实透明背景，纹理只留在笔触中，不复制署名或水印。
- **验收简练程度**：缩小先看见表情、动物身份与配饰，再看到少量毛簇。若首先看到密集毛纹、复杂针织、照片阴影或层层高光，应减少内部刻画；仅有粗糙纹理但造型仍写实，也不匹配此参考。
